# Evaluación 1 - Figuras Geométricas

Aplicación Ionic + Angular para calcular el perímetro de un círculo o de un triángulo.

## Requisitos

- [Node.js](https://nodejs.org/) (versión LTS recomendada)
- npm (incluido con Node.js)

## Instalación

1. Clona o descarga el proyecto.
2. Abre una terminal en la carpeta del proyecto.
3. Instala las dependencias:

```bash
npm install
```

## Ejecutar el proyecto

Para iniciar el servidor de desarrollo:

```bash
npm start
```

También puedes usar:

```bash
ionic serve
```

Luego abre en el navegador:

```
http://localhost:4200
```

## Uso de la aplicación

1. En el select **Figura Geométrica**, elige **Círculo** o **Triángulo**.
2. Ingresar los datos requeridos segun la firgura (radio o lados).
3. Presiona **Calcular perímetro** para ver el resultado.
